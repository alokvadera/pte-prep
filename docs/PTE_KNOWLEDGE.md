# PTE Academic — everything this project needs to know

Researched from Pearson's own Score Guide (2026 edition, 22 question types),
the Institution Score Guide (July 2025), the Official Guide, and Pearson's
scoring pages. Every claim below is sourced. Where Pearson does **not** publish
something, that is stated explicitly, because guessing is worse than admitting
the gap.

## 1. Structure

**1.1 — 65 to 75 scored questions, 22 question types, in one sitting.** (A p.4)

**1.2 — Three timed sections, run back to back with no scheduled break.** (A, F)

| Part | Section | Guide A timing | Legacy timing (C/D/E) |
|---|---|---|---|
| 1 | Speaking & Writing | 76–84 min | 54–67 min |
| 2 | Reading | 23–30 min | 29–30 min |
| 3 | Listening | 31–39 min | 30–43 min |

Part 1 grew because SGD (2–3 items × ~3 min) and RtS (2–3 items) were added in
2025. Legacy timing is still widely quoted online; **A is current**.

**1.3 — Computer-delivered, headset with microphone, at a test centre.** (F)

**1.4 — The section introduction and countdown count towards section time.** (F)

**1.5 — One unscored item: the Personal Introduction, at the start of Part 1.** (F)

**1.6 — Item order within each section is fixed by type**, and each test version
is balanced for total length, so counts vary between sittings. (A, F)

**1.7 — 8 of 22 types are *integrated* and score two communicative skills.** (A)

| Type | Skills |
|---|---|
| Repeat Sentence | Listening + Speaking |
| Re-tell Lecture | Listening + Speaking |
| Summarize Group Discussion | Listening + Speaking |
| Summarize Written Text | Reading + Writing |
| Summarize Spoken Text | Listening + Writing |
| Highlight Correct Summary | Listening + Reading |
| Highlight Incorrect Words | Listening + Reading |
| Write from Dictation | Listening + Writing |
| *(the other 14 types each score a single skill)* | |

Getting this wrong distorts every skill score, because an item's points feed
**both** skills.

**1.8 — Scoring order in the current guide's own worked diagram** (A p.8,
Describe Image):

```
Content ──(== 0)──▶ No further scoring. Total = 0.
   │
   └──(> 0)──▶ Pronunciation + Oral Fluency ──▶ Total
                                        │
                                        ├─▶ communicative skill score
                                        └─▶ overall score
```

**1.9 — Content 0 or Form 0 ⇒ zero points for the whole item**, regardless of
how well the other traits scored. Examples Pearson gives of zero-scoring
responses (A p.7): an essay on a completely different topic; an essay under 120
words; a response that does not deal with the prompt because of memorised,
pre-prepared material.

**1.10 — Some types get a human expert review on top of the AI score**
(A p.15): Describe Image, Re-tell Lecture, Respond to a Situation, Summarize
Group Discussion, Summarize Written Text, Write Essay, Summarize Spoken Text.
Write Essay also gets expert review of Development/Structure/Coherence and
General Linguistic Range. Content disagreements between AI and human go to a
second human. Pronunciation and Oral Fluency are **AI-only**.

**1.11 — "Content is scored by both AI and human. If there is a disagreement
between the AI and human, a second human will make the final judgement."** (A p.8)

## 2. Scores

**2.1 — Overall score: 10–90, half-point increments.** (A)

**2.2 — Each of the four skills: 10–90.** (A)

**2.3 — "The overall score is not an average calculation of the communicative
skills scores."** (B, A — stated twice, unambiguously.) Pearson states
mechanically that it is a single IRT scaling over all 65–75 item scores, each
weighted by item difficulty.

> **Consequence for us.** Any per-skill mean we show is our own construction,
> not Pearson's. It must be labelled as such. The overall score cannot be
> derived from the skill scores, and the reverse is also not guaranteed.

**2.4 — Pearson does not publish the item-score → scaled-score conversion.** The
IRT parameters, item calibration and equating are undisclosed. *(prepex.ai and
every serious analysis concur; nothing contradicts this in A/B.)*

**2.5 — Overall-score reliability is 0.93**, within the practical range
**53–79**. (B p.12)

**2.6 — "Reliability is not uniform across the score scale"** — IRT means the
test is less reliable toward the extremes. So a 20 or an 88 is a less
trustworthy number than a 60. (B p.11)

**2.7 — CEFR bands for the overall score** (B pp.18–20; corroborated verbatim
on pearsonpte.com — G):

| Score | CEFR |
|---|---|
| 85–90 | C2 |
| 76–84 | C1 |
| 59–75 | B2 |
| 43–58 | B1 |
| 30–42 | A2 |
| 10–29 | A1 or below |

**2.8 — Pearson does not publish per-skill CEFR bands.** Only overall. (B)

**2.9 — The 10–90 scale is the Global Scale of English**, aligned to CEFR, and
developed with 6,000+ teachers across 50+ countries. (B / efficacy report)

**2.10 — Pearson publishes only the 10–90 scale.** There is no "60–120" scale in
Pearson documentation. Institutions set admissions thresholds on the 10–90 scale
or reference the official PTE Academic concordance with IELTS.

**2.11 — IELTS concordance (overall).** (B, July 2025)

| IELTS | PTE |
|---|---|
| 9.0 | 90 |
| 8.5 | 86–89 |
| 8.0 | 79–85 |
| 7.5 | 71–78 |
| 7.0 | 63–70 |
| 6.5 | 55–62 |
| 6.0 | 47–54 |
| 5.5 | 39–46 |
| 5.0 | 31–38 |
| 4.5 | 24–30 |

The July 2025 study also publishes separate IELTS concordance ranges for each
PTE skill. It does not publish per-skill CEFR bands. The study's table begins at
IELTS 4.5; it does not give a concordance below that band.

Pearson's disclaimer (A p.12): *"Any attempt to predict a score on a particular
test, based on the score observed on another test, will contain measurement
error."*

## 3. The 22 question types

Scoring column: **C/I** = correct/incorrect. **PC** = partial credit.

### Part 1 — Speaking & Writing

| # | Type | Count | Scoring | Skill(s) | Traits |
|---|---|---|---|---|---|
| 1 | Read Aloud | 6–7 | PC (error count) | **Speaking** only | Content; Pronunciation; Oral Fluency |
| 2 | Repeat Sentence | 10–12 | PC (word sequence) | Listening + Speaking | Content; Pronunciation; Oral Fluency |
| 3 | Describe Image | 5–6 | PC (trait scores) | Speaking | Content; Pronunciation; Oral Fluency |
| 4 | Re-tell Lecture | 2–3 | PC (trait scores) | Listening + Speaking | Content; Pronunciation; Oral Fluency |
| 5 | Answer Short Question | 5–6 | **C/I** | **Listening** | Vocabulary |
| 6 | Summarize Group Discussion | 2–3 | PC (trait scores) | Listening + Speaking | Content; Pronunciation; Oral Fluency |
| 7 | Respond to a Situation | 2–3 | PC (trait scores) | Speaking | Content; Pronunciation; Oral Fluency |
| 8 | Summarize Written Text | 2 | PC (trait scores) | Reading + Writing | Content; Form; Grammar; Vocabulary |
| 9 | Write Essay | 1 | PC (trait scores) | Writing | Content; Form; Development-Structure-Coherence; General Linguistic Range; Vocabulary Range; Spelling; Grammar |

> **Breaking change (1.10/1.11 above):** Read Aloud scored *Reading and Speaking*
> in C/D/E. **In A it scores Speaking only.** Online material still says both.

### Part 2 — Reading

| # | Type | Count | Scoring | Skill |
|---|---|---|---|---|
| 10 | Fill in the Blanks (Dropdown) | 5–6 | PC, 1 per correct blank | Reading |
| 11 | Multiple Choice, Multiple Answers | 2–3 | PC, **+1 correct / −1 incorrect**, min 0 | Reading |
| 12 | Re-order Paragraph | 2–3 | PC, **1 per correct adjacent pair** | Reading |
| 13 | Fill in the Blanks (Drag and Drop) | 4–5 | PC, 1 per correct blank | Reading |
| 14 | Multiple Choice, Single Answer | 2–3 | **C/I** | Reading |

### Part 3 — Listening

| # | Type | Count | Scoring | Skill |
|---|---|---|---|---|
| 15 | Summarize Spoken Text | 1 | PC (trait scores) | Listening + Writing |
| 16 | Multiple Choice, Multiple Answers | 2–3 | PC, **+1 correct / −1 incorrect**, min 0 | Listening |
| 17 | Fill in the Blanks (Type In) | 2–3 | PC, **1 per correct word spelled correctly** | Listening |
| 18 | Highlight Correct Summary | 2–3 | **C/I** | Listening + Reading |
| 19 | Multiple Choice, Single Answer | 2–3 | **C/I** | Listening |
| 20 | Select Missing Word | 1–2 | **C/I** | Listening |
| 21 | Highlight Incorrect Words | 2–3 | PC, **+1 correct / −1 incorrect**, min 0 | Listening + Reading |
| 22 | Write from Dictation | 3–4 | PC, **1 per correct word spelled correctly** | Listening + Writing |

**3.1 — Only three of 22 types carry negative marking:** MC Multiple Answers
(Listening), MC Multiple Answers (Reading), Highlight Incorrect Words. Every
other partial-credit type is positive-only. (A pp.40, 44)

**3.2 — Re-order Paragraph arithmetic.** N textboxes ⇒ N−1 adjacent pairs, so
**max item score = N−1**. Score = count of adjacent pairs the candidate placed
in the correct relative order. No negative marking. (A p.40.)

> Pearson publishes **no** worked example for this in any version. The
> derivation above is arithmetic from the published rule, not a quotation.
> Example (ours): key A→B→C→D, candidate submits A→B→D→C ⇒ pairs (A,B) ✓,
> (B,D) ✗, (D,C) ✗ ⇒ **1 of 3**.

**3.3 — Read Aloud Content, the complete published rule** (A p.15, unchanged
since 2012):

> "Each replacement, omission or insertion of a word counts as one error.
> **Maximum score: depends on the length of the question prompt**"

There is **no** published error-count → point table. The common community
approximation (max = prompt word count, content = words read correctly) is *not*
Pearson's statement and must not be attributed to them.

**3.4 — Repeat Sentence Content, 0–3** (A p.17). Errors = replacements,
omissions and insertions **only**. *"Hesitations, filled or unfilled pauses,
leading or trailing material are ignored in the scoring of content."*

| Score | Descriptor |
|---|---|
| 3 | All words from the prompt, in the correct sequence |
| 2 | At least 50% of words from the prompt, correct sequence |
| 1 | Less than 50% of words from the prompt, correct sequence |
| 0 | Almost nothing from the prompt |

**3.5 — Content scale is not uniform.** It is 0–6 for Describe Image, Re-tell
Lecture, Summarize Group Discussion, Respond to a Situation and Write Essay;
0–4 for Summarize Written Text and Summarize Spoken Text; 0–3 for Repeat
Sentence; and unpublished for Read Aloud.

**3.6 — Form bands are type-specific and hard-edged** (A):

| Type | 2 | 1 | 0 |
|---|---|---|---|
| Write Essay | 200–300 words | 120–199 or 301–380 | <120 or >380; all caps; no punctuation; bullets/very short sentences only |
| Summarize Spoken Text | 50–70 words | 40–49 or 71–100 | <40 or >100; all caps; no punctuation; bullets/very short sentences only |
| Summarize Written Text | *(scale is 0–1 only)* | 1 = one single complete sentence | not a single complete sentence, or <5 or >75 words; all caps |

**3.7 — Answer Short Question: Vocabulary 0–1.** 1 = "Appropriate word choice in
response"; 0 = "Inappropriate word choice in response." Correct/incorrect, so
there is no partial band. (A p.24)

**3.8 — Answer Short Question scores Listening only** in the current guide.
C/D/E said Listening and Speaking.

## 4. Trait scales

**4.1 — Pronunciation 0–5** (A pp.45–46). The top band was relabelled
"Native-like" → **"Highly proficient"** in A. Numeric bands unchanged.

| | Label | Key phrase |
|---|---|---|
| 5 | Highly proficient | Easily understood; appropriate assimilation and deletion; stress correct in all words and at sentence level |
| 4 | Advanced | Clear and unambiguous; a few distortions that do not affect intelligibility |
| 3 | Good | Most consonants and vowels correct; some consistent errors make a few words unclear |
| 2 | Intermediate | Some consonants and vowels consistently mispronounced; at least 2/3 of speech intelligible; listeners may need to adjust to the accent |
| 1 | Intrusive | Many mispronunciations; difficulty understanding about 1/3 of words; strong intrusive accent |
| 0 | Non-English | More than 1/2 of speech unintelligible; non-English stress and syllabification |

**4.2 — Oral Fluency 0–5** (A pp.45–46). Note band 1 is **"Limited"** here but
**"Intrusive"** under Pronunciation.

| | Label | Key phrase |
|---|---|---|
| 5 | Highly proficient | Smooth rhythm and phrasing; no hesitations, repetitions, false starts or phonological simplifications |
| 4 | Advanced | No more than one hesitation, one repetition, or one false start |
| 3 | Good | Acceptable but possibly uneven speed; more than one hesitation but most words in continuous phrases; no long pauses; not staccato |
| 2 | Intermediate | Uneven or staccato; ≥1 smooth three-word run; no more than 2–3 hesitations/repetitions/false starts; **one** long pause but not two or more |
| 1 | Limited | Irregular phrasing; multiple hesitations/repetitions/false starts; one or two long pauses |
| 0 | Disfluent | Slow and laboured; most words isolated; more than one long pause |

**4.3 — Pronunciation and Oral Fluency apply to six types:** Read Aloud, Repeat
Sentence, Describe Image, Re-tell Lecture, Summarize Group Discussion, Respond
to a Situation. Not to Answer Short Question, Summarize Written Text or Write
Essay.

**4.4 — Grammar 0–2** (essay / SWT / SST). 2 = correct, no hindrance;
1 = errors but no hindrance; 0 = defective, could hinder communication.

**4.5 — Spelling 0–2.** 2 = correct; 1 = one error; 0 = more than one error.

**4.6 — Vocabulary / Vocabulary Range 0–2.** 2 = appropriate or broad and
idiomatic; 1 = some errors/circumlocution; 0 = basic, insufficient.

**4.7 — Development, Structure and Coherence 0–6, Write Essay only.** 6 =
effective logical structure, clear argument developed at length, well-developed
intro and conclusion, cohesive paragraphs, varied connectives used effectively.
0 = no recognisable structure.

**4.8 — General Linguistic Range 0–6, Write Essay only.** 6 = variety used
with ease and precision, no restriction, errors rare and minor. 0 = meaning not
accessible.

**4.9 — Write Essay Content 0–6.** 6 = addresses in depth, full command,
expanded with specificity, supported with subsidiary points and examples.
0 = does not properly deal with the prompt.

**4.10 — Summarize Written/Spoken Text Content 0–4.** 4 = comprehensive, full
comprehension, effective paraphrasing, extraneous detail removed, skilled
connectives. 0 = no comprehension.

**4.11 — Describe Image / Re-tell Lecture / SGD / RtS Content 0–6**, with the
same shape across all four: 6 = full comprehension, own words, expanded,
well-connected with effective connectives; 2 = mostly inaccurate, incomplete,
focuses on non-essential information; 1 = on topic but communicates nothing
meaningfully; 0 = too limited to score higher.

## 5. How traits combine — and what Pearson does not say

**5.1 — The current guide says only "the scores of these traits are used to
calculate the final total score for the question."** (A p.8) No weights, no
formula.

**5.2 — Wording drift that matters.** The 2012 guide (E p.59) said the traits
**"add up to"** the item score and published a 15-point max for Write Essay
(Content 3, Form 2, DSC 2, Grammar 2, GLR 2, Vocabulary Range 2, Spelling 2).
That additive wording was **removed in 2021** and has not returned. The 2012
additive model is therefore *not* guaranteed to still hold.

**5.3 — Pearson's own framing of the opacity** (E p.7): *"The scores indicated
for each trait undergo a number of complex calculations to produce the total
item score."* And from G: *"Scores are based on the complexity of the question."*

**5.4 — The item → 10–90 step is IRT with undisclosed parameters.** (B pp.11–12)

### The four things Pearson does not publish — plan around them

1. **Read Aloud**: the error-count → point conversion, and what "depends on the
   length of the question prompt" means numerically.
2. **Trait → item score** weighting, for any constructed-response type.
3. **Item score → scaled score**, for overall and for skills. IRT parameters.
4. **Per-skill CEFR bands.**

**5.5 — Consequence for this project.** Exact reproduction is impossible. What
is defensible: implement every *published* rule exactly (scoring mode, per-unit
counts, negative marking, the Content/Form gate, skill routing, Form length
bands, CEFR bands), and estimate only the undisclosed steps. Label the
constructed parts as estimates, per item, and never imply otherwise.

## 6. The four mistakes this project had made

Recorded because they are the ones a reader is most likely to reproduce.

1. **CEFR bands invented.** The implementation used C2 ≥ 81 / C1 ≥ 71 / B2 ≥ 61.
   Pearson's actual bands are 85 / 76 / 59. Every band was wrong, so every
   result was mislabelled. A score of 78 is C1, not C2; 62 is B2, not B2-at-70.

2. **Re-order Paragraphs scored all-or-nothing.** Pearson awards 1 per correct
   adjacent pair with a max of N−1. Treating it as all-or-nothing both
   over-rewards a lucky correct order and, worse, makes the most recoverable
   item type in Reading look unrecoverable.

3. **Negative marking at half strength.** MC Multiple Answers and Highlight
   Incorrect Words both use **−1 per wrong** (A pp.40, 44). The implementation
   used −0.5 and −0.75. This systematically inflated scores on exactly the types
   where the penalty is the whole point of the task.

4. **Single-skill attribution.** `Item.skill` was a single enum, so 9 of 22
   types credited only one skill. Repeat Sentence and Re-tell Lecture feed both
   Listening and Speaking; Write from Dictation and Summarize Spoken Text feed
   both Listening and Writing. This distorted all four skill scores, and
   therefore the whole profile.

Two more, less severe:

5. **The Content/Form gate was absent.** A response with zero content but a
   beautiful delivery scored on the delivery. Pearson scores the whole item at
   zero.

6. **Type-specific Form bands were generic.** A 380-word essay and a 380-word
   summary were treated the same. Pearson bands them 0, 1 or 2 by exact word
   count, per type.
