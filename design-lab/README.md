# PTE Prep — design lab

A standalone, interactive redesign study informed by familiar PTE preparation patterns. The five directions are different product experiences rather than palette swaps. Use the controls at the top to compare the same homepage and product flows across them.

## Run locally

From the repository root:

```sh
python3 -m http.server 4173 --directory design-lab
```

Then open <http://localhost:4173>.

## Directions

- **Prep Academy** — course-led home, study sequence, question-type discovery.
- **Practice Hub** — learner dashboard with persistent section navigation and next actions.
- **Mock Test Library** — catalogue-led browsing for full, sectional, and question practice.
- **Exam Simulator** — reduced-distraction timed task view and test controls.
- **Score Coach** — score-first review, skill breakdown, and targeted next drill.

All screens are illustrative front-end mocks; recording and scoring are not connected to the production app. The concepts use common category patterns, not copied assets or branding.

## Reference patterns

- [Pearson PTE AI Practice](https://www.pearsonpte.com/pte-academic/preparation/ai-practice/) — full and sectional mocks, question practice, skill feedback, progress tracking.
- [APEUni](https://www.apeuni.com/?locale=en) — skill-focused AI-scored practice and study tools.
- [AlfaPTE](https://alfapte.com/) — full/sectional mock choices and custom mock test option.
- [Gurully PTE](https://www.gurully.com/pte) — mock catalogue with test duration, section count, access labels, and score review.
